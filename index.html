Tips & Tricks

When building social media posts for new releases, create multiple posts and use the social media scheduler to plan each post ahead of time up until the day of the release. Make sure to include a post for the day before as a Last Chance post, as well as a post for the day of as a Releasing Today post.
You can create backgrounds inspired by a single bowling ball by giving this prompt to ChatGPT and loading an image of the ball with the prompt. For a different look & feel, change the last sentence to the style that you want.
Can you please create an 8 1/2" x 11" background image that I can use on a flyer? It should use colors from this image for inspiration. Can you make it a combination of modern and grunge?
